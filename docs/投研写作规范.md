# 投研写作规范

版本1，2026-11-12。适用于报告、预测解释、图册、路演和讲稿；生成和编辑前先读本规范与shared/writing-skills.json。

每节回答具体投资问题，直接写企业、经营变化、竞争、利润资本现金与价值。章节功能由内容决定，研究卡的字段结构不直接当阅读稿结构。完整编辑单元先读完，诊断成立才重组；结构健全时局部修改。

保留作者判断强度、主体、期间、币种、单位、聚合口径、正负号、公式参数、来源及否定条件。推测仍为推测，管理层预期仍归管理层；发现矛盾或证据越界另列内容问题，不以润色掩盖或认可。

删除重复无增量的防御句、说教、空泛总结和装饰性排比。实质边界改写为具体范围、经营条件、观测与影响，关键风险紧邻相应判断。候选/审核状态集中说明，必要局部标识；来源、核验和复算保留可展开附录与依据JSON。

四技能分工：humanize-paper诊断问题—命题—证据—经营机制—竞争解释，使用中文lexicon第5节，不套IMRaD；academic-deai主导语义保持编辑；jiang-ai小步核对与跨节重复复查；aigc-reduce只作受保护片段与模板候选定位。用户规则优先：不设修改率、词频和句长配额，不轮换专业术语，不添模糊限定，不强制重排或DOCX，不承诺检测分数。

持续流程：读取当前来源绑定及编辑源→记录结构判定与命题映射→按完整单元编辑→逐项核来源、数字与条件→成果中心导出新MD/HTML/依据JSON→检查重生成、预览和下载。保留旧成果、旧指纹、账本与人审。数字重复可合并，以命题—来源映射核保真，计数扫描只作线索。

阅读稿编辑源为公司work/writing/reader.json，段落带研究卡/字段锚点。成果中心可保存编辑源，修订历史存同目录revisions。导出绑定编辑源、规则、技能清单、原件及计算；研究卡变化后须重新核对编辑源，停止静默沿用旧正文。未编写阅读稿的新增研究导出问题草稿，停止逐字段堆叠；作者须按本规范补充连贯正文。

恢复技能：python scripts/check_writing_skills.py [--skills-root <目录>]；默认INVESTMENT_WRITING_SKILLS或当前用户.codex/skills。记录的管理员路径是本轮实际调用证据，不是恢复的固定前提。全局技能不随项目覆盖安装，项目内规范和生成器可独立运行。
