# 泡泡玛特证券研究结论

## 生意凭什么持续

消费者为角色与收藏体验付款。泡泡玛特用授权、设计、门店和触达密度扩大新IP销售。2026H1剔除THE MONSTERS后集团收入同比增40.35%。中国区实体门店销售除以期初期末平均店数，代理店效增34.22%。门店批次、可比开业时长与地区混合使此代理有别于成熟店同店。

## 最强反方是租金和库存压缩现金

集团毛利率由70.34%至69.68%，年化存货周转由4.33次至1.80次。成熟店销量、折扣和售后退货需与毛利分开验证。现金租金口径把使用权折旧和已计短期、可变费用加回，现金租赁流出整体扣一次。

## Q3区间与Q4反解

2025H2可复算收入23,243.78百万元，占全年62.62%。两份Q3经营更新均以同比区间披露。若2025Q3占当年H2一半，2026Q3降幅45%–50%及阶段15 H2为上年53%的条件要求2026Q4收入约5,927.16至6,508.26百万元，同比-49.00%至-44.00%。表格并列其他季度权重。

## 现价与估值差额

各交易所当地 2026-11-12 收盘 143.40 HKD，阶段15基准 215.04，本轮三情景从 48.53 到 536.37，基准 166.65。基准 WACC 5.40%，终值现值占企业价值 75.83%。 同一阶段15现金口径下，原校正、移除、按渠道校正分别为215.04、193.45、173.88港元。重新统一租金后，需求、租金及占用联动网格为118.08至204.52港元。

## 最先改变判断的指标

要看Q4绝对收入，以及同期同口径成熟店销量、折扣后毛利与库存账龄。若新IP增长能抵消爆款衰减，会出现库存消化与现金回收一起改善。若靠开店或折扣冲量，租金与占用将反向拖累。

## 依据与研究边界

阶段15锁定基线 769e6e443aba87c7a94704f4da5efb876d7ba65f。本轮复核原文披露 16 项，当前Fact 24 条，确认身份保存在原账本。估值变化按逐项替换次序归因。主体、口径、报告日、原件定位及模型现金行附在总览表。期后资料供后验检查。
