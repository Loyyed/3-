# 投研写作规范 v2

2026-11-19 生效，适用于后续报告、预测说明、图册、路演及讲稿。沿用版本 1 的证据、语义保护和研究卡约定。补充材料 8 写作原文为「交代清楚谁做了什么 将所有防御性语句放在最后」。

正文直接交代经营行动者、行为和结果。写清谁付款、谁履约、谁承担库存或资本、谁做出管理决定及其时点。没有可核依据时保留未知责任，不添人名、动机或行动。研究责任同样标清。Agent 的定位、复算和解释，学生的回原件、质疑、纠错与采纳，由实际执行者和事件支持。简要写入依据，必要时就地说明来源身份。

正文沿同一投资命题展开所见变化、解释和反方。经常重复的自我限制、方法提醒和过程声明压缩后放在最后的「依据与研究边界」。改变数值和主张含义的限定紧邻相关句子，如固定组合下、税前或税后、管理层预计、拟议和解尚需批准。重大负面事实、反证、风险和关键适用域仍是正文分析材料。一般语气编辑不得改变事实、预测或权限。

作者先画论证和证据关系，再检查数字、权利、时点和段落功能。沿用 humanize-paper、academic-deai、jiang-ai 和 aigc-reduce 的项目适配。anti-defensive-writing 仅辅助删除过程套话和确定叙事主次。其论文中回避不利比较的建议不适用于投研。报告必须保留有实质影响的不利样本及裁决依据。技能记录 [见 v2 补充映射](writing-skills-v2.json)。

正式写作前打开 [作者提示](author-brief.md)。已发布报告依旧使用其原写作版本和指纹。课程任务、方法、视觉和版本关系见 [准备台](index.html)。
