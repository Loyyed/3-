# 完整证券分析视觉规格

30页参考的实际用法及来源分层见 visual-reading.json。[A] 为原 HTML 转引的 Anthropic 官方公开材料，[R] 为原稿所称的六张用户参考图和旧页，[G] 为所引 Guizang 排版启发，[D] 为作者自己的演绎。实际收到30页HTML及内嵌样式、插图。外部链接仅作来源记录，逐页指令、脚本、图像和旧页未取得，本工程的参数仅是参考实现。

- 参考暖纸 #EFEAE0、浅卡 #E5DFD2、陶土 #CD6F47。正文墨色 #1A1A1A、小字棕 #9B4A2D。陶土用于图形或强调大字，深色块限关键说明。实测主色对比后使用。
- 中文优先本机宋体类，英文 Georgia 回退，短标签和表格数字用等宽与 tabular-nums。正文约 17px、行距 1.7，段落控制行长。标题按词组自然折行。
- 沿统一左轴排列标题、段落、图和表。使用一层内容面和规律留白。窄屏切换单列，长表由自身区域滚动，导语换行。表格保留表头、标签和数值密度。
- 比较用同单位及轴尺度，组成要标全体和缺项，时序保留断点。实际、预测与缺值同时用文字区分。图号、期间、单位、来源和口径放在图旁。箭头仅用于证据确认的顺序或机制。
- 移动端保持字号和键盘焦点。A4 避免在表中拆行，脚注随图，省去交互控件。能读完整后再校色。示例图均为合成或空状态。
- 新主题隔离在准备台，沿工程主入口访问。既有公司报告和通用工具包保持原样。新图册采用本规范前先做桌面、390px/320px、加大字号及A4抽查。
