# 后续作者提示

先确定一个主要研究对象、一条可被经营证据推翻的投资命题、证券权利和信息窗口。按业务与客户、竞争、治理、财务与资本、预测、估值及反方跟踪组织论证。每节说明谁做了什么、何时行动、结果怎样，保留直接反证和替代解释。以经营证据推导预测及估值，写清市场价格和模型价值的范围、日期及归属。

源和计算的末尾说明记录真实的行动者、来源位置、作者取舍、教学条件、复算及尚未解决的范围。压缩并后置方法性防御句。保留会改变相邻主张含义的限定和重大风险。研究责任以可见实际动作及提交记录为准。

图表先问需要比较、组成、时序或联系中的哪一种，再选形式。标清编号、标题、来源、期间、单位、缺值、实际和预测。每页以一个问题为重心，兼做桌面、窄屏和纸张检查。参照 [视觉规范](visual-spec.md)。页数、装订和签核按实际确认的课程口径。

本文件用于完整分析启动后的写作。本轮模板暂不填充公司观点、价格、模型或人名。
