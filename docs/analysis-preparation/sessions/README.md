# Sessions 收件与索引

课程稿要求电子报告与 Sessions 同打包，分别设成员文件夹，并附打包 README。成员信息、贡献、学生手算及独立复核均由实际人员提供，此处没有实际会话出口或提交记录。阶段12保有公开可重跑的计算文件、成果和证据定位，可作为未来会话索引的目标路径，无法替代原会话。

1. 每位成员导出参与研究的原始会话记录，提供实际角色、时间窗口、文件和与章节/模型的联系。选用原工具提供的可见日志。
2. 在本机先留一份私有原件。审核员另审提交副本，删除令牌、API key、个人隐私与无关材料。原始隐藏推理不属于供提交对象。
3. 使用 sessions-manifest-template.json 记录收到的文件、来源、哈希、提交者、时段和具体缺口。以真实学生核验、质疑、纠错和决策的可见记录索引贡献。留空表示未收到。
4. 每成员私有目录置于工程 .local/course-sessions 下。正式电子包装置于同一忽略区，按所列 README 范例整理。提交教师需要另行执行实际提交动作。

已知缺口：当前与此前对话没有本工程可用的完整原始导出及可见工具轨迹包。未收到各组员的独立会话、姓名、学号、组长确认及成员贡献。请在日后按实际导出填入，访问本工程文件和交接摘要不能重建这些轨迹。

已脱敏的单份实际导出用 scripts/prepare_course_sessions.py 收取。运行 --help 查看成员槽位、提交人、覆盖日期及章节/模型参数。收件产生带SHA的本地凭据，人工标注真实可见行为及审核结果。相同指纹在同一成员目录复用凭据。
