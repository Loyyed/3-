# 涪陵榨菜证券分析

## 交易时点与价值

2026-11-12 当地未复权收盘 11.42 CNY。阶段14基准 14.18，阶段15基准 13.98，压力 10.34，改善 18.22。

## 证据窗口

财年覆盖 2010—2025，共 16 年。近期采用 2024—2026 同期披露，2026最新完整报表为 Q3。2010更正版、2016更新版与原件分列。收入准则、租赁、SKU及经销与直销分类变更需逐段核。应收与转固后利用率会改资本回报。

## 商业模式与资本占用

家庭消费者为熟悉的口味与上架可得性付款。经销商集中接货再向终端铺货，涪陵承担腌制、原料库存和基地投入。品牌回报要同时体现在同规格售价、渠道周转和现金。2016—2020年适合观察规模和利润率能否同升，2021—2022年用来观察量价与原料错位，2023—2025年检验旧基地盈利能否覆盖新投入。 上市后经销铺货与品类集中至收入平台与扩建的年度样本，分段增速、利润率、现金转化和投入回报见依据及总览筛选表。

## 量价、结构和现金

2024至2025年，食品收入增量44.91百万元，销量贡献25.26百万元，组均价和结构贡献19.65百万元。同期集团销售费用增59.39百万元。将量价增收与集团费用并列可检验利润是否兑现。独立核算渠道需用各渠道毛利扣返利、运费、人工和回款成本，分配前不能据此判断直营贡献为负。

## 最近披露形成的参数更新

2026年前三季累计收入增3.45%，现金购建支出398.69百万元，期末应收143.58百万元。新渠道扩张也可能放宽账期，回款改善还需经销与直营收现拆分。基准采用销量初始增2.0%、组均价与结构增0.8%，再按留出偏差校正销量。若基地转固后吨成本升高且折扣或返利扩大，压力利润率更合适。

## 条件估值和终值

基准 WACC 6.55%，稳定增长 2.00%，稳定核心利润率 29.62%，新增资本回报 11.50%，终值占企业价值 74.21%。历史和模型重估 -0.19，近期 -0.01，口径 +0.00 CNY/股。

## 反方、相对估值与下一项证据

结论分歧集中于直营增量来自终端动销或信用期延长。下一步以固定SKU净价、经销商到终端库存、期后收款以及新老基地吨折旧区分。千禾与海天可作货架和经销比较，需先核品类盈利与经销责任。

## 依据与研究边界

当前原披露 Fact 32 条。阶段14、长期收入新增确认及六批跳转可从账本追到原件与确认事件。 本稿估值按条件模型，正文判断为解释或预测。年度经营投入资本子集为净营运交易余额、固定资产、在建、无形及使用权资产的可得部分。用相邻年度平均存量计算代理ROIC，新增回报仅在投入增量为正时报告。
