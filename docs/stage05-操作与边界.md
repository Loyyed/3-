# 成果闭环操作与验收

启动根启动研究工作台.cmd，8780选择公司→研究卡保存→成果中心填写标题、公司内模型/计算文件相对路径和来源ID→生成MD/HTML/依据JSON→预览/下载。各公司outputs/catalog.json是版本索引，根outputs/index.html跨公司汇总。其他类型支持文本格式导入登记，不自动生成路演或图表。

版本解析以已纳入最新方法为准；旧依赖可保留原版本，新增旧版必须给historical_reason，且版本必须真实存在。编辑卡保留type、全部methods、impacts及needs_review。单独解决影响需basis、versions、真实actor，原影响不删除。公司材料直接提炼不得扩大scope；跨公司通用化使用generalize动作提供去公司化副本文本和conversion_reason。

实际报告绑定卡片内容指纹、方法版本、显式指定的真实模型/计算文件、来源原件ID和SHA。变更后分开显示文件完整性和当前有效性。未登记依赖的其他旧模型不会自动被发现，不声称覆盖全部旧底稿。已纳入的计算文件/参数文件/真实导出报告依赖在独立夹具实测，非type标签代替。

正式公司仅生成标明空研究状态的起步草稿，不补造公司结论，实际人审均null；合成故事与模型只存在独立夹具。
